# Anti-AFK
A lightweight, universal desktop utility designed to prevent system idle status and keep your screen active without needing game-specific hooks.

## Features
Universal Operation: Works globally across any application or desktop environment without interfering with your workflow.

Simple GUI: Clean, easy-to-use interface built with Python and Tkinter.

Professional Installer: Distributed via a custom Windows installer package for effortless setup.

## Installation
Download the latest AntiAFK_Installer.exe from the releases page.

Run the installer and follow the on-screen setup wizard.

Launch Anti-AFK from your desktop shortcut or start menu.

### Source & Building (Note: not important)
If you want to compile the application from source or build the installer yourself:

Compile the executable using cx_Freeze:

```
bash
python setup.py build
```


Compile the installer script using Inno Setup by opening MAIN-SETUP.iss and pressing F9.
